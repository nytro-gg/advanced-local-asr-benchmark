# Experimental Evidence

The six screenshots in this directory document selected earlier development and model experiments. They provide supporting evidence of Faster-Whisper transcription, language detection, Python implementation, Parakeet memory behavior, audio processing and CLI setup.

These are historical supporting screenshots, not terminal screenshots of the matched November 2026 Small/Medium benchmark runs. Those exact measurements are documented in `results/results.md` and `docs/benchmark-methodology.md`.

Private audio, full private transcripts and per-run local metadata are intentionally not published.
